# Plan: UI Modernization - Inventory & POS

## Goal
Modernize the UI to be clean, card-based with blue theme.

## Design Specs
- **Style**: Card-based with rounded corners (12px), generous spacing, subtle shadows
- **Color**: Blue primary (#2563eb), light gray backgrounds (#f8fafc), white cards
- **Typography**: Clean sans-serif, consistent sizing

## Implementation Plan

### Phase 1: Global Styles
1. Update `globals.css` with new color palette and base styles
2. Add card component styles
3. Add consistent button styles
4. Add form input styles

### Phase 2: Dashboard (`/dashboard`)
1. Modern stat cards with icons
2. Remove "Demo Mode" warning, make it subtle

### Phase 3: Sidebar Navigation
1. Modern sidebar with better spacing
2. Add icons for navigation items
3. Better hover states

### Phase 4: Categories Page (`/dashboard/categories`)
1. Card-based category display
2. Better modal styling
3. Attribute tags styled nicely

### Phase 5: Products Page (`/dashboard/products`)
1. Modern table with better spacing
2. Styled product cards in grid
3. Better modal for adding products

### Phase 6: Polish
1. Consistent spacing/padding
2. Smooth transitions/hover effects
3. Loading states with skeletons
4. Empty states with illustrations
